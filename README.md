# Shubham Chess Academy — website

One-page static site for Shubham Singh's online chess coaching (ages 4–15), with a Hindi
version, three parent guides and a free puzzle PDF. No server, no build step.

- `site/` is the deployable root, published to GitHub Pages by `.github/workflows/pages.yml`.
- `CLAUDE.md` — how to work on it, the style contract, and the feedback log.
- `NOTES.md` — facts and their sources, what is still a placeholder, how renders are verified.
- `research/` — the 20-site competitor survey the feature list came from.

Open locally: `open site/index.html`.
